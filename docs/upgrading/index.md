# Upgrading

Every Trill release gets a page here, with what it needs from your instance (and how to do it) and what's new.

To upgrade an instance, run `npm run update` in its folder (see [Updating](../updating.md)). It brings in the newest stable release, keeps your settings and email templates, applies the database migrations and offers to deploy.
